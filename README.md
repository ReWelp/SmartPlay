# SmartPlay

Intelligent YouTube playback extension. Skips silence, dynamically adjusts speed, trims filler words, and tracks how much time you save.

## Features

- **Silence Skipper**: Skips dead air automatically.
- **Adaptive Speed**: Dynamically adjusts playback speed based on the video's speech rate.
- **Smart Features**: Filler word trimmer, chapter navigator, keyword jump, and auto-pause.
- **Video Modes**: Auto-detects Music, Movie, Podcast, or Lecture modes to adjust feature sets automatically.
- **Channel Memory**: Remembers settings per YouTube channel.

## Installation (Unpacked)
1. Go to `chrome://extensions/`
2. Enable "Developer mode" in the top right.
3. Click "Load unpacked" and select the folder containing this extension.

## Privacy
SmartPlay respects your privacy. It processes audio and transcript data entirely locally in your browser. No video data or browsing history is sent to any servers. See `PRIVACY.md` for more details.

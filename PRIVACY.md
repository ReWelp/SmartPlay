# Privacy Policy for SmartPlay

**Last Updated:** May 2026

## 1. Information Collection
SmartPlay operates entirely locally within your browser. 
- It processes video audio using the Web Audio API to detect silence.
- It accesses YouTube transcripts to enable the "Filler Trimmer" and "Keyword Jump" features.
- All settings and configurations are stored securely using Chrome's local storage and sync storage.

## 2. No Data Collection or Sharing
SmartPlay does not transmit, collect, or share your browsing history, YouTube viewing habits, or audio data with any external servers or third parties.
The optional YouTube Data API key (if provided in settings) is used solely to query the video category to enable "Auto-Mode" features.

## 3. Contact
For any privacy concerns, please contact the developer via the GitHub repository issues page.
